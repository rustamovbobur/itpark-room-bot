# Вход по ссылке из Telegram и стрелки расписания

На сайте больше не нужно вводить Telegram ID. Для нового пользователя бот выдаёт ссылку до регистрации; имя, отдел и код доступа сотрудников вводятся непосредственно на сайте. Для существующего пользователя ссылка сразу открывает расписание. Стрелки слева и справа от даты переключают дни; календарь остаётся доступен.

## Обновление существующего проекта через PowerShell

Скачайте `IT_Park_Meeting_Rooms_Link_Update.zip` в «Загрузки», затем выполните:

```powershell
cd "C:\Users\user\Desktop\itpark-room-bot"
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\IT_Park_Meeting_Rooms_Link_Update.zip" -DestinationPath "." -Force
npm.cmd test
npm.cmd run db:remote
git add src/bot.js src/site.js src/web.js src/worker.js src/logo.js migrations/0003_site_signup.sql migrations/0004_site_links.sql tests/bot.test.js tests/web.test.js README.md UPDATE_LOGIN_RU.md
git commit -m "Add Telegram link login and date arrows"
git push
npm.cmd run deploy
```

Если предыдущий ZIP уже установлен, Wrangler применит только `0004_site_links.sql`. Если нет — сначала применит `0003_site_signup.sql`, затем `0004_site_links.sql`. **Миграцию выполняйте до публикации**: без таблицы ссылок команда `/site` не заработает. Новые таблицы не удаляют брони. Архив не содержит `wrangler.toml`, `.dev.vars` или токен. Настройку webhook повторять не требуется.

## Первый вход

1. Откройте https://itpark-room-bot.itpark.workers.dev/ и нажмите «Открыть бота в Telegram». Нажмите Start. Бот пришлёт кнопку «Открыть Meeting Rooms». Если бот уже открыт, можете отправить `/site` вручную.
2. Нажмите кнопку из сообщения бота. Если профиль новый, сайт попросит имя, отдел и **код доступа сотрудников**, который предоставляет ответственный за комнаты. Регистрация в боте не нужна.
3. Если профиль уже был, расписание откроется сразу. Браузер сохраняет вход до 30 дней. Ссылка живёт 10 минут и используется один раз: при истечении запросите новую командой `/site`.

Сайт не запрашивает Telegram ID. Персональную ссылку получает сам пользователь в чате с ботом. Не пересылайте её другим: любой, кто получит эту ссылку до первого использования, сможет войти от вашего имени. Для старого способа `/web` есть запасной вход внизу страницы.

Для перехода между соседними датами нажимайте **←** и **→** по сторонам календаря. На первом и последнем доступном дне соответствующая стрелка неактивна.
