# Обновление v2: профиль и админ-панель

В архиве только изменённые файлы. Распакуйте его в корень существующего проекта с заменой файлов. Сохраните локальные изменения через git commit до замены, если редактировали код самостоятельно.

Обновляются:
- src/bot.js
- tests/bot.test.js
- README.md
- TEST_REPORT.md
- UPDATE_V2_RU.md

wrangler.toml, .dev.vars, база и зависимости не заменяются. Миграций нет. Существующие сотрудники и брони сохраняются.

## Профиль

«Мой профиль» и /profile показывают сохранённые имя и отдел. Есть отдельные кнопки изменения каждого поля. /start возвращает в меню без регистрации, если профиль заполнен. При первой регистрации имя и отдел остаются обязательными. Уже созданные брони сохраняют имя и отдел на момент создания.

## Админ-панель

Два условия доступа: ваш числовой Telegram ID в ADMIN_IDS и правильный секрет ADMIN_PASSCODE. Код сотрудников STAFF_ACCESS_CODE остаётся отдельным.

Команды в PowerShell из папки проекта:

```powershell
notepad wrangler.toml
```

В существующем разделе [vars] замените ADMIN_IDS на свой числовой ID, полученный командой /id в боте. Например:

```toml
ADMIN_IDS = "123456789"
```

Для нескольких администраторов укажите ID через запятую. Не изменяйте database_id и binding.

```powershell
npm.cmd test
npx.cmd wrangler secret put ADMIN_PASSCODE
```

В приглашении Wrangler введите выбранный код администратора. Код не нужно записывать в git, wrangler.toml или исходники. Эта операция добавляет один новый секрет, остальные сохраняются.

```powershell
git add src/bot.js tests/bot.test.js README.md TEST_REPORT.md UPDATE_V2_RU.md wrangler.toml
git commit -m "Remember profiles and add protected admin panel"
git push
npm.cmd run deploy
```

При ошибке остановитесь на ней. Повторный telegram:setup не требуется: /admin уже обрабатывается кодом. В стандартном Telegram-меню команд эта команда пока не отображается — отправьте её вручную.

После публикации: /admin → код администратора.

В панели доступны:
- текущие и будущие брони по всем комнатам;
- история всех броней, включая отменённые;
- Telegram ID владельца каждой брони и ID самой брони;
- сотрудники с именами, отделами и Telegram ID;
- просмотр конкретной брони и поиск по полному ID;
- отмена любой брони с отдельным подтверждением;
- создание брони обычным мастером; владельцем становится вошедший администратор;
- статистика: всего, текущие/будущие, отменённые;
- выход из админ-панели.

Сессия администратора действует один час. После 5 неправильных кодов действует блокировка на 15 минут. /start не сбрасывает счётчик. Права перепроверяются при отмене, в том числе если сессия истекла после открытия подтверждения. Удаление ID из ADMIN_IDS и публикация обновления прекращают админ-доступ этого пользователя.

Отмена сохраняет запись и ID отменившего для истории и освобождает время. Физического удаления записей нет. Отдельное уведомление владельцу об административной отмене в этой версии не отправляется — сообщите ему самостоятельно. Создание от имени другого Telegram-пользователя, редактирование комнат и управление доступом сотрудников через панель в эту версию не входят.

Проверка после публикации: откройте профиль два раза, измените одно поле, отправьте /start. Войдите в /admin, найдите пробную бронь, проверьте её Telegram ID и отмените. С обычного аккаунта /admin должен отказать в доступе.
