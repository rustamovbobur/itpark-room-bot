# Meeting Rooms — история администратора и цвета сотрудников

## Установка в Windows PowerShell

Скачайте IT_Park_History_Colors_Update.zip в папку «Загрузки». Выполняйте команды по очереди. При ошибке остановитесь и пришлите её текст.

```powershell
cd "C:\Users\user\Desktop\itpark-room-bot"
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\IT_Park_History_Colors_Update.zip" -DestinationPath "." -Force
npm.cmd test
npm.cmd run db:remote
git add src tests migrations/0006_user_colors.sql UPDATE_HISTORY_COLORS_RU.md
git commit -m "Add admin booking history and personal colors"
git push
npm.cmd run deploy
```

При применении миграции Wrangler может попросить подтверждение: согласитесь, если показана миграция `0006_user_colors.sql`. Она добавляет таблицу цветов; комнаты, профили и бронирования не удаляются. Миграцию нужно выполнить до публикации нового кода. После публикации обновите страницу через Ctrl+F5.

Архив не содержит wrangler.toml, токенов или паролей. Используются существующие настройки вашего проекта. Он включает все актуальные исходники и тесты, в том числе предыдущие исправления. Устанавливается поверх существующего проекта, где уже применены миграции 0001–0005.

## История

На сайте откройте «Профиль» → «Войти как администратор» и введите действующий код администратора. Доступ проверяется по Telegram ID из ADMIN_IDS и действующей админ-сессии.

В разделе «Администратор» добавлена полная таблица рабочего дня. Она показывает прошедшие часы сегодняшнего дня и пять предыдущих календарных дней по Ташкенту. Например, 30 сентября доступны 25–30 сентября. Будущие даты доступны в обычном периоде бронирования. Выбор даты — стрелками или календарём. Кнопка «Обновить» вверху страницы обновляет открытый раздел.

В таблице показаны неотменённые брони. Нажмите встречу, чтобы увидеть данные сотрудника, комментарий, Telegram ID и ID брони. Ниже таблицы находится список всех броней выбранного дня, включая отменённые. В нём видны статус и ID администратора или сотрудника, отменившего бронь, если они записаны в базе.

Для прошедших дат форма создания брони скрыта. Завершённые и отменённые брони доступны для просмотра. История использует уже существующие записи D1, поэтому начнёт показывать предыдущие дни сразу после установки, если брони в эти дни были.

## Персональные цвета

Каждому сотруднику автоматически назначается постоянный случайный цвет при первом обращении сайта к его профилю или броням. Начальные цвета уникальны в базе; случайное совпадение при назначении автоматически обрабатывается повторным выбором.

Изменить цвет можно в «Профиль» → «Цвет моих бронирований» → «Сохранить изменения». Есть предпросмотр. Два сотрудника могут вручную выбрать одинаковый цвет. Выбор сохраняется за Telegram ID и применяется к старым и новым карточкам этого сотрудника, включая брони, созданные через бота или администратором от его имени.

Цвет используется для рамки и светлого фона; текст остаётся тёмным и читаемым. Свои встречи дополнительно помечены «Вы». Цвета видны всем сотрудникам на сайте; в Telegram текстовые сообщения остаются обычными.

## Проверки и границы

60 автоматических тестов: бронирование и защита от пересечений, вход и права администратора, граница истории в 5 дней, прошедшие часы, отменённые записи, постоянство и уникальность начальных цветов, одинаковые пользовательские цвета, проверка формата, конкурентное назначение и большие списки истории. Используются SQLite, локальный D1 и DOM-harness JavaScript. Отрисовка в настоящем браузере и работа с production-аккаунтами в этой сессии не проверялись.

Сборка проверена через wrangler deploy --dry-run. Для публикации выполните команды выше на своём компьютере.
