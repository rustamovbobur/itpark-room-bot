# Сайт бронирования IT Park

Сайт работает в том же Cloudflare Worker и использует существующую D1. Брони в Telegram-боте и на сайте видны в общем расписании. Двойную запись по-прежнему блокирует уникальный ключ получасовых слотов в базе.

Адрес после публикации: https://itpark-room-bot.itpark.workers.dev/

На сайте есть общее расписание для 5-го, 6-го и 9-го этажей, выбор даты на ближайшие 30 дней, создание броней с шагом 30 минут, необязательный комментарий, «Мои брони» с отменой и редактирование профиля. Экран сделан для ноутбука, на телефоне сетка прокручивается горизонтально.

## Вход

Для первого входа отправьте уже знакомому боту https://t.me/Meeting_room_IT_Park_bot команду `/web`. Вставьте 10-символьный код на странице. Код действует 10 минут и используется один раз. Сотрудник должен быть зарегистрирован в боте: это позволяет использовать его существующее имя и отдел, не создавать новые логины и пароли. После входа браузер хранит защищённую сессию 30 дней. Кнопка «Выйти» удаляет сессию.

## Обновление рабочего проекта — Windows PowerShell

1. Загрузите ZIP обновления. Из папки существующего проекта (`C:\Users\user\Desktop\itpark-room-bot`) распакуйте файлы поверх проекта:

```powershell
cd "C:\Users\user\Desktop\itpark-room-bot"
Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\IT_Park_Room_Website_Update.zip" -DestinationPath "." -Force
```

Если браузер сохранил ZIP в другом месте, укажите фактический путь. Архив не содержит `.dev.vars` или `wrangler.toml` и не меняет ваш ID базы, Telegram токен, код сотрудников или настройки админа.

2. Проверьте код и примените новую миграцию **до публикации Worker**:

```powershell
npm.cmd test
npm.cmd run db:remote
```

Подтвердите применение `0002_web.sql`, если Wrangler спросит. Создаются таблицы кодов сайта и сессий; существующие пользователи, брони и комнаты сохраняются. Миграция применяется один раз. Не запускайте её вручную повторно через `d1 execute`.

3. Сохраните версию в GitHub и обновите работающий Worker:

```powershell
git add src/bot.js src/worker.js src/web.js src/site.js migrations/0002_web.sql tests/web.test.js README.md TEST_REPORT.md WEBSITE_UPDATE_RU.md
git commit -m "Add shared meeting room booking website"
git push
npm.cmd run deploy
```

4. Откройте `https://itpark-room-bot.itpark.workers.dev/`. В боте отправьте `/web`, вставьте код и проверьте расписание. Сделайте тестовую бронь на сайте; она должна сразу появиться в Telegram-боте. Отмените её через «Мои брони» на сайте и проверьте освобождённое время.

`npm run telegram:setup` повторять не нужно: настроенный webhook продолжает принимать команду `/web`. В стандартном меню команд Telegram она не появится автоматически — вводите вручную.

## Проверка и эксплуатация

Сайт не показывает расписание неавторизованным людям. API проверяет сессию и Origin для изменений. Одноразовый код расходуется транзакцией и защищён от параллельного использования. Кнопка «Забронировать» не удерживает время до отправки формы: при одновременной попытке второй человек получает сообщение, что время уже занято, и расписание обновляется.

Панель администратора остаётся в Telegram (`/admin`). Создать свою бронь и отменить её можно и на сайте. Если необходимо, чтобы HR вообще не пользовался ботом даже для первого входа, следующим отдельным шагом можно согласовать авторизацию через корпоративный аккаунт организации.

Рабочий сайт обновится только после `npm.cmd run deploy`. Код с сайта в GitHub сам по себе ничего не публикует.
